# Agent Note: 大项目、草稿身份与模型上下文压缩

Status: implemented

## Problem

固定文件数量、总文本和请求次数门禁阻止大项目和长工具任务；运行状态与可编辑草稿共用节点标识，替换或刷新会丢失编辑意图。窄窗口双栏挤压画布，原始 JSON 结果也难以定位对应版本的问题源码。

## Decision

### 草稿与呈现边界

WorkflowStudio 持有独立 draftId/revision、工作流、项目路径、排除规则、选择、模式、选中节点与高级 JSON 缓冲。启动绑定当时身份、修订及执行范围；不匹配时草稿节点不显示旧运行状态，结果保留名称/时间/项目/范围和差异提示。运行快照只读，按该次配置重跑复用运行配置，当前草稿由原启动入口运行。

本地格式 simple-workflow-draft-v1 保存 data 和一步 undo，自动恢复且不重放运行。编辑后 350ms 防抖，离页同步刷新；不保存工作区源码或后台密钥。高级 JSON 按当前草稿中的节点 ID 持有，不随节点组件卸载丢失；未应用缓冲与表单变化冲突时要求明确应用或重载。无效/未应用 JSON 阻止服务器保存及启动。替换提供取消/保存后替换/直接替换，服务器保存失败不执行替换；存储失败显示提示并在无法离页落盘时触发离开提醒。

布局存储与窗口适配分离，中央至少 400px，双侧栏不足时仅显示 activeSide（默认配置），放大恢复存储偏好；结果栏按内容高度。移动端宽度门槛继续为 768px。

### 扫描、授权与源码版本

打开项目只保留索引和统计，默认目录折叠；搜索只展开匹配祖先，可见树扁平化虚拟滚动，不为隐藏后代生成 DOM。显式范围与实际覆盖数分别计算；搜索/折叠不变更授权。扫描支持 AbortSignal，逐文件句柄 finally 关闭；排除建议只有用户点击才加入规则，再次打开生效。

POST /api/workspaces 默认保持 JSON；Accept: text/event-stream 返回 progress/complete/error，可选 stats 不破坏旧脚本。GET /api/runs/[id]/source 绑定会话、相对路径、完整版本与行范围；由运行副本或基线及保存差异重建并计算完整版本，找不到返回明确不可用，禁止用当前磁盘替代。

### 模型调度与不变量

移除 1000 文件/选择、16 MiB 总文本、64 KiB 历史、512 KiB 累计读取、21 次请求及各层 20 次调用门禁。保留单文件 1 MiB、单次读取 256 KiB、路径/权限、白名单逐次审核及事务校验。每节点十分钟总时限包含压缩/审核；请求及命令各 120 秒，手动取消继续生效。

使用 deepseek-flash、Chat Completions；maxOutputTokens 可选，新节点省略 max_tokens，显式旧值保持，手动范围 1–393216。窗口 1048576 tokens，默认输出余量按非思考 8192、思考 65536、max 思考 131072 或显式配置计算。usage 校准新增历史估算，达到可用输入空间 80% 时安排压缩，估算不拒绝请求。

压缩位于整批工具完成后；旧历史分块交给无工具、关闭思考的摘要请求后合并，保留最近四组完整助手/工具交互及 reasoning_content。重建保留原系统/任务、摘要、后台版本/固定范围/原问题/已执行验证/补丁状态检查点。检查点只记录补丁状态而不重复完整源码；摘要是导航，不能成为读取或测试证据。

仅明确上下文超限触发一次进一步压缩和重试；参数/鉴权/输出截断不算超窗。不可压缩或再次失败保留已执行进展并提示缩小范围。摘要 usage 和耗时计入节点；取消后的迟到摘要不提交新历史。响应兼容可空字段，移除固定 4 MiB 门禁，响应流结束或异常释放读取器。

原始交互、摘要请求/响应和压缩记录保存到 interactions/<run-id>.jsonl，目录 0700/文件 0600，随运行删除，不通过 SSE 重复推送全文。运行 compactions、usage.purpose 都为可选字段，兼容历史记录。

## Alternatives considered

- **保留旧保守门禁**：资源消耗更易预测，但阻止已授权的大项目和长任务；用户明确选择移除，改由时限、取消与模型窗口压缩控制运行。
- **扩大或按比例缩小双栏**：保留两侧可见信息，但无法同时保证最小侧栏和中央宽度；采用最近侧栏切换并保留宽屏偏好。
- **按磁盘当前文件定位问题**：实现简单且总能读到文件，但无法证明与运行证据同版；只恢复并校验运行版本。
- **截断历史或把摘要视为验证证据**：成本低，但会破坏工具配对、思考历史或证据可信度；保留完整最近组与后端权威检查点。

## Consequences

大项目和长任务不再被上述应用内数量门禁阻断，草稿与旧结果可独立检查。没有引入无限资源承诺：副本/基线/版本计算仍用本机内存磁盘；保留 HTTP 1 MiB 请求体、工作区/运行登记数量及必要的文本分页、事务、审核约束。摘要会产生额外调用与费用，固定任务或最近四组本身过大时明确失败。

## Verification

[本次验收](../../../../docs/reviews/2026-10-25-implementation/verification.md)记录 93 项单元、14 项 HTTP、lint/类型/构建、四种窗口截图及真实 DeepSeek 聚焦冒烟。大窗口耗尽、高调用次数由确定性夹具验证；实际存储禁用及完整浏览器故障注入未在本轮动态覆盖，不将边界单测表述为浏览器全量通过。
