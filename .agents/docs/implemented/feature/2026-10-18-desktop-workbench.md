# Agent Note: 桌面 IDE 工作台重构

Status: implemented

> 本文保留桌面重构时的 1100×680 门槛与验收记录。当前窗口限制由[仅限制移动端视图](2026-10-18-mobile-viewport-gate.md)替代；其他布局及运行边界继续适用。

## Problem

原工作台缺少欢迎入口和可调整的面板尺寸，项目文件以目录／完整路径列表呈现。用户要求参考桌面终端的紧凑分区与蓝色强调色，并明确选择仅支持桌面、可收起和拖动面板、欢迎页及可折叠目录树。

## Decision

工作台使用左侧图标导航、资源面板、中央内容、右侧配置和中央下方结果面板。首次打开进入欢迎页，支持打开项目、创建完整／仅审查模板、继续编辑和查看历史。选择模板替换当前流程，打开项目不替换流程；欢迎页和历史页暂时隐藏编辑侧栏，返回编辑恢复原状态。

### 状态与接口边界

- `WorkflowStudio` 继续持有工作流、项目范围、运行快照和唯一 SSE 订阅。编辑画布、资源与配置组件保持挂载，通过 `hidden` 切换显示；因此导航不丢失画布视口和节点 JSON 草稿，不导致审核过期。仅首次显示已测量画布时适应全部节点，普通导航不会重置视口。
- 命令审核位于结果面板外，跨页面常驻。新审核展开结果；收起结果不影响批准／拒绝。现有运行、应用、撤销、历史清理及严格 `mode: real` 协议保持原样。
- 界面不新增终端、连接管理或文件编辑器。工作流导入导出、后端 API、版本与授权 schema 不包含布局状态。

### 布局、主题与支持范围

布局偏好独立存储在 `simple-workflow-layout-v1`：默认资源宽 260px、配置宽 300px、展开结果高 260px，左右显示、结果收起。资源宽 220–420px，配置宽 240–480px，结果高至少 140px；视口进一步限制尺寸，中央至少保留 400px 宽和 160px 高（支持范围内）。窗口尺寸变化仅限制当前呈现，不覆盖已保存偏好；但刷新读取仍有[结果高度截断缺陷](#已知限制与缺陷)，不能保证较高窗口的尺寸原样恢复。

使用 `useSyncExternalStore` 提供稳定服务端快照、浏览器存储恢复及窗口变化订阅；坏 JSON、无效类型或不可用存储回退默认布局，存储失败后仍支持当前会话调整。分隔线采用 Pointer Capture 和可访问 separator，支持方向键、Shift 加速、Home／End；顶栏提供重置。

默认主题继续为 system，沿用 `simple-workflow-theme`、首屏主题脚本及 React Flow 的主题同步。深浅主题均采用蓝色强调色、细边框、小圆角和低阴影。全局 CSS 与 CSS Modules 的职责及第三方样式加载规则保持不变。

最低支持内容视口为 1100×680。更小窗口仅展示扩大提示，工作台交互区域（包括审核按钮）设置 `inert`，但不卸载执行状态、快照或连接。审核需恢复支持尺寸后处理；小窗独立审核入口的建议见 [Deferred](#deferred)，不属于当前已实现能力。移除旧手机／平板抽屉及其焦点约束 Hook；后续恢复触屏支持须重新设计导航和画布操作，不能仅删除窗口提示。

### 目录树

从后端提供的平面文件路径在前端建立层级，目录优先并按名称排序。展开／折叠使用本地组件状态，不发送请求、不更改选择。目录授权仍允许范围内新增／修改／删除；继承父目录授权的后代勾选且禁用，部分后代被选时父目录显示半选。去掉父目录授权后，之前显式选择的后代仍保留，不能把半选显示误当作目录授权。

- [真实工作流修正](../simplification/2026-10-17-real-workflow-only.md)：部分重叠，互链；运行能力和协议继续以该记录为准。
- [MVP 记录](2026-10-14-simple-workflow-mvp.md)：部分重叠，互链；继续沿用授权、快照、应用与审核边界。
- [Turbopack 故障记录](../bug-fix/2026-10-14-turbopack-cached-port-permission-error.md)：无关，未改变构建加载规则。

## Alternatives considered

- **仅更新视觉**：修改量小，但无法满足欢迎入口、目录树及面板调整需求，因此重组前端布局。
- **保留手机抽屉**：可继续提供小屏操作，但用户明确选择只支持桌面，因此移除旧断点交互并给出最低窗口提示。
- **仅深色主题**：适配成本更低，但用户要求保留现有主题偏好，因此同时适配浅色与系统模式。

## Consequences

布局偏好独立于业务协议，导航和尺寸调整不影响执行连接。桌面面板支持保存偏好，但刷新恢复仍受[已知缺陷](#已知限制与缺陷)限制；手机与较小平板不提供完整操作。目录树仍基于完整文件列表构建，不引入懒加载或编辑文件能力。

### 已知限制与缺陷

以下行为由浏览器检查确认；未实施的修复方向见 [Deferred](#deferred)。

| 场景               | 当前行为与影响                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 低于最低视口       | 1000×650 时，整个工作台含审核按钮被 `inert` 禁用，并被扩大窗口提示遮挡。连接保持不代表审核可操作，需恢复支持尺寸后处理。                                        |
| 支持尺寸内收起结果 | 1100×680，左 260／右 382、中央 400px 时，结果收起容器为 36px，工具栏换行后约 57.6px，运行状态被底栏遮挡。页面根节点没有溢出不能证明内部无重叠。                 |
| 较高窗口刷新       | 1920×1440 中结果高度设为 616px，刷新后变成 454px；[布局读取逻辑](../../../../lib/studio/layout.ts)固定按 1920×1080 适配，较高窗口的结果高度偏好在读取时被截断。 |

代码检查还确认：[PanelResizer](../../../../components/panel-resizer.tsx) 未记录拖动发起者的 `pointerId`，后续触点可以覆盖起点或提前结束拖动。在支持触摸的桌面设备上可能造成尺寸跳变；该项未通过浏览器多点触摸复现。

## Verification

2026-10-18 的检查记录：`pnpm typecheck`、`pnpm lint`、`pnpm build` 通过；`pnpm test` 的 70 项单元测试及 `pnpm test:integration` 的 12 项 HTTP 集成测试通过，未调用付费模型。新增 [studio 单元测试](../../../../tests/studio.test.ts)覆盖损坏的布局存储、窗口缩小时的中央空间与偏好保留、目录分组去重、父目录授权继承和路径前缀边界。

浏览器检查使用本机生产预览，覆盖以下交互，未修改业务实现。[已知限制与缺陷](#已知限制与缺陷)仍未解决，不能据此宣称全部交互验收通过。

- 1100×680、1440×900、1920×1080 的深浅主题均采集截图；含中文多级目录和较长文件名时，页面根节点没有横向或纵向溢出。结果面板内部、目录树和配置区域各自滚动。
- 欢迎页默认入口、完整／仅审查模板、打开项目、添加节点后自动配置；欢迎／历史往返保留当前工作流名称与未提交高级 JSON；历史隐藏侧栏，返回恢复编辑状态。
- 三处分隔线的指针拖动、方向键调整；显隐与尺寸刷新恢复、重置布局。恢复检查不包含对所有窗口尺寸的保证，较高窗口的反例见[已知限制与缺陷](#已知限制与缺陷)。
- 目录选择、继承授权、目录折叠后选择数量不变、重新展开后后代仍勾选且禁用。
- 保存／加载及导出后重新导入；导出仅含 `formatVersion`、`name`、`nodes`、`edges`，不含布局数据。
- 使用仓库[模型协议替身](../../../../tests/fixtures/model-transport.mjs)和测试专用哨兵密钥，在独立临时项目／数据目录完成模拟模型运行；未调用付费模型。新审核展开结果，收起结果、切换欢迎／历史保留审核；恢复桌面尺寸后批准本地测试，运行可继续，支持节点输入输出、各轮／最终差异、应用与撤销，并核对临时文件内容。另验证重新运行、欢迎页取消运行、历史刷新／查看和 JSON 报告下载。
- 历史删除与备份确认入口仍在，未勾选确认时删除按钮禁用；浏览器检查未实际删除历史，删除协议由 HTTP 集成测试覆盖。

焦点轮廓、键盘即时调整、pointer capture、忙碌反馈、短时颜色过渡及 reduced-motion 处理通过静态检查。浏览器多点触摸和实际禁用 localStorage 时的异常回退尚未动态验证；存储回退仅有纯函数异常数据测试及存储访问 try/catch 的代码审查。新增 4 项 studio 测试都是辅助函数测试，未自动挂载组件；浏览器人工检查不能替代组件交互回归测试。

## Deferred

低于最低视口时提供独立审核入口的建议尚未实施，是否将其纳入支持范围例外仍待明确。该建议不构成当前的小窗审核保证；若采纳，须单独记录审核入口、焦点及超时行为的决定，不能将审核例外等同于恢复手机／平板工作台支持。

收起工具栏采用内容自适应高度或可达的单行布局、将存储解析校验与实际窗口适配分开、保存并校验活动触点以忽略后续触点，均是尚未实施的修复方向。修复后仍需验证支持尺寸内的内容可见性、较高窗口尺寸的刷新往返，以及多点触摸下的拖动行为。
