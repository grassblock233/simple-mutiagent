# Agent Note: 精简重复测试与布局实现断言

Status: implemented

## Problem

用户要求审查当前测试并删除不必要的测试。默认模板测试逐项复述生成器中的横坐标、行坐标与标签，布局微调即需同步修改测试；工作流格式和取消测试存在可合并的重复设置，循环轮数样本包含重复路径。

## Decision

审查 `tests` 中单元测试、HTTP 集成测试及模型传输夹具后，本次只精简 `workflow.test.ts`，将默认测试集从 75 项减到 71 项：

- 删除逐节点匹配 280px／240px 坐标和固定标签的测试。六节点、格式及语义校验保留；具体排布和无遮挡由浏览器检查承担，自动测试不固化样式参数。
- 将独立条件白名单测试合并到工作流格式拒绝测试，分别验证非法字段、操作符、值。原测试一次给出三个非法项，任意一项拒绝都会掩盖另两项；合并后独有检查保留且彼此独立。
- 将执行器不响应取消的测试合并到迟到结果测试：先等待取消完成，再释放执行器，并等待一个事件循环后比较完整快照，证明挂起不会阻塞收束、迟到结果不会改写状态。设置 1 秒测试超时，避免取消回归导致无限等待。
- 循环上限保留 1 和 5，移除重复的 2 轮样本；5 轮仍覆盖多次循环、逐轮编号和上限退出，成功提前退出另有独立测试。

权限校验、命令审核、文件事务恢复、验证门禁、旧工作流兼容、HTTP 路由接线及模型协议测试继续保留。名称相似但处于不同边界的测试不直接按标题判重；运行时端到端测试可在 `pnpm test` 中独立发现集成错误，HTTP 测试验证正式路由和会话绑定。

## Alternatives considered

- **删除全部旧循环测试与夹具**：可以进一步减少维护代码，但旧保存／导入工作流仍受支持，删除它们会失去现行兼容性回归，因此保留。
- **按同名行为删除跨层测试**：可以减少重复运行，但调度器、真实文件运行时和 HTTP 接线有不同失败模式，保留各层的独立价值，只删同层冗余。

## Consequences

测试用例减少四项，取消和条件拒绝的独有行为继续覆盖。布局参数不再由单测逐项锁死，布局变化仍需浏览器验证。本次不改变产品代码、测试入口或模型替身策略，也不触发付费模型联调。

`pnpm test` 71 项通过；`pnpm lint`、`pnpm typecheck`、`git diff --check` 通过。HTTP 集成测试及其夹具未修改，本次未重新执行；不将单元测试结果表述为生产 HTTP 或真实模型验收。
