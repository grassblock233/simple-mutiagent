# Agent Note: 仅交付真实工作流并修复验证门禁

Status: implemented

## Problem

修复节点可以沿用旧版本的成功验证；同版本失败的必要检查会被其他成功检查掩盖；历史容量满时无法删除未载入记录；模型 smoke 脚本在输出不兼容时仍成功退出。产品同时只保留真实运行，开发阶段的合成演练不属于产品。

## Decision

产品只接受 `mode: real` 的运行请求；工作区、范围和模型配置是运行前提。演练执行器、演练请求 schema、场景字段、默认示例范围与版本、模拟命令白名单、界面入口及报告分支均不属于产品。

引擎构造必须显式提供工作区上下文和授权函数，调度器测试通过 [tests 内的注入夹具](../../../../tests/engine-fixture.ts)建立上下文。夹具只验证调度，不提供模型、命令或文件事务的实体验收证据。

非真实模式的磁盘记录不进入历史列表，也不能恢复、重试、导出或应用；启动不改写它们，磁盘原记录保留，不静默删除或改标为真实结果。真实记录保持格式 v1，确认应用、事务日志与撤销继续有效。

### 验证与运维修正

验证记录在单次节点执行内同时绑定命令身份（可执行文件与参数）及执行版本。提交时，每条已请求的必要检查都必须具有最终内容哈希的证据；另一条成功检查不能替代尚未重新执行的检查。旧版本记录保留在命令证据中，不能证明新版本通过。

同版本任一必要检查失败即执行失败，缺失或拒绝即验证未完成；当前版本没有任何成功验证时同样不能放行。修改后必须重新检查。版本恢复到已验证的相同内容时，可以复用同一节点执行内对应哈希的证据；同版本失败不会被之后的成功覆盖。

删除历史直接校验运行状态和全部事务日志，不需要先注册到受 50 条上限限制的内存运行表；活动运行、其他会话已占用记录、未解决恢复事务仍然不可删除。[模型 smoke 脚本](../../../../scripts/deepseek-smoke.ts)断言响应去除首尾空白后等于 `OK`，空值或其他文本以非零状态退出。

### 测试替身的归属

[HTTP 集成测试](../../../../tests/http.integration.ts)在临时真实工作区上调用正式 API，使用真实读取、补丁、命令和文件事务。[模型协议替身](../../../../tests/fixtures/model-transport.mjs)仅通过测试子进程的 `NODE_OPTIONS --import` 预加载，并要求测试专用哨兵密钥；生产代码没有模型地址开关、测试路由或自动批准入口。

[smoke 测试](../../../../tests/smoke.test.ts)通过独立传输夹具验证脚本退出状态。单元测试注入 runner，不能视为真实模型证据。

## Alternatives considered

- **隐藏演练按钮并保留后端**：改动较少，也保留原 HTTP 夹具；但仍暴露模拟运行能力，不符合删除整个功能的目标，因此完整删除产品路径。
- **把演练记录转换为真实历史**：可以统一列表结构；但会把固定数据伪装成模型与进程证据，因此保留磁盘原记录并拒绝加载。
- **给生产模型端点增加测试配置**：方便 HTTP 测试接入替身；但会把测试控制面带入产品，因此仅在测试子进程预加载传输替身。

## Consequences

产品运行入口只对应真实工作流，避免将固定响应误作模型与进程证据。离线测试保留调度及正式应用路径的回归覆盖，无需把测试控制面加入生产代码。

无模型密钥时仍可编辑流程及查看真实历史，但不能启动运行；非真实模式记录如需清理，由维护者在数据目录手动处理。传输夹具需要随模型工具协议维护，离线通过不能扩大为官方模型联网验收或宿主隔离保证。

文件与网络隔离继续按 MVP 决定延期。需要新增无密钥体验或兼容其他模型协议时，应重新评估入口、证据标识和夹具维护成本，不得恢复隐式演练分支。

2026-10-17 的交付修正完成时，`pnpm test` 的 66 项单元测试、`pnpm test:integration` 的 12 项生产 HTTP 测试全部通过。

`pnpm typecheck`、`pnpm lint`、`pnpm build` 及 `git diff --check` 通过。

单元回归覆盖测试后修改、同版本必要检查一败一成、切换检查不能替代先前检查、修改后重新验证、演练记录不转换及 smoke 有效/空响应的退出状态。生产 HTTP 回归覆盖正式运行、来源/会话/CSRF、幂等、审核拒绝、取消、SSE、后台重启、实际命令批准与执行、真实历史应用/撤销、非当前请求拒绝和满容量历史删除及恢复事务保护。

独立临时数据目录中的生产浏览器检查确认：无模型密钥时启动禁用并说明缺少的条件，运行设置没有演练控件，浏览器控制台无错误。该检查未覆盖真实运行的完整浏览器交互；临时服务与数据只用于 2026-10-17 的检查。边界见 [MVP 验证](../feature/2026-10-14-simple-workflow-mvp.md#verification)。

2026-10-17 的修正未运行付费联网脚本。官方联网证据只有 [MVP 的 2026-10-14 记录](../feature/2026-10-14-simple-workflow-mvp.md#verification)；2026-10-17 的修改未经官方模型联网复验。
