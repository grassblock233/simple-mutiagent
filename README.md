# Simple Workflow

通过本地 Web 界面编排 Agent，对项目进行代码审查、修复和复审。

## 安装与启动

需要 Linux、Node.js 24 和 pnpm 12。在仓库根目录创建 `.env.local`：

```dotenv
DEEPSEEK_API_KEY=替换为你的实际密钥
# 可选：运行数据目录，不能与被审查项目互相包含
# SIMPLE_WORKFLOW_DATA_DIR=/home/你的用户名/.local/share/simple-mutiagent
```

不要提交密钥；修改配置后需重启服务。未配置密钥时只能编辑工作流。

```bash
pnpm install
pnpm dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。如需生产运行：

```bash
pnpm build
pnpm start
```

服务仅供本机单进程使用，请勿公开到网络。

## 使用步骤

1. 输入项目绝对路径，或点击“浏览目录”选择目录，再点击“打开项目”。勾选允许修改的文件或目录。
2. 创建默认“单轮修复”流程，按需添加、连接和配置节点。默认流程先审查，有阻塞问题时修复并复审，最多修复一次。
3. 选择“确认后写入”或“自动写入”，启动工作流。运行期间修改配置只影响下一次运行。
4. 逐条批准或拒绝检查命令；选择自动写入也需要审核命令。
5. 查看问题和差异。确认模式需手动应用，自动模式验证通过后整批应用；应用后可撤销，也可导出报告或查看历史。

“浏览目录”需要服务运行在 Linux 图形会话中，并安装 `zenity` 或 `kdialog`；不可用时手动输入路径。建议使用宽度至少 768px 的浏览器窗口。

源码会发送到 DeepSeek API，获批命令以本机用户权限执行。请只用于信任的项目，并仔细审核命令。
