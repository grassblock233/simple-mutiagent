# Simple Workflow

在本地 Web 界面编排审查、修复和复审 Agent，通过 DeepSeek Flash 处理真实项目。支持文件范围选择、条件分支、有限修复循环、逐次命令审核、确认或自动写回，以及备份撤销和 Markdown/JSON 报告。

项目面向 Linux、单用户、单个 Node.js 进程。源码会发送到 DeepSeek API；检查命令在项目副本内以本机用户权限运行，未启用文件与网络隔离，获批命令仍可能修改宿主文件或其他项目。请只用于信任的项目，并逐次确认检查命令；日志、差异和备份可能包含源码，应按敏感材料管理。

## 启动

需要 Node.js 24 与 pnpm 12。在仓库根目录创建 `.env.local`：

```dotenv
DEEPSEEK_API_KEY=替换为你的实际密钥
# 可选：专用运行数据目录
# SIMPLE_WORKFLOW_DATA_DIR=/home/你的用户名/.local/share/simple-mutiagent
```

数据目录与被审查项目必须分开，不能互相包含。密钥不要加 `NEXT_PUBLIC_` 前缀，也不要提交到 Git；修改配置后重启服务。没有密钥时仍可编辑工作流，但不能启动运行。

```bash
pnpm install
pnpm dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。生产运行：

```bash
pnpm build
pnpm start
```

服务只监听回环地址，请勿公开到网络或以多个后台进程运行。

“浏览目录”需要服务运行在 Linux 本地图形会话中，并安装 `zenity` 或 `kdialog`（优先使用 Zenity）。选择窗口显示在服务所在桌面；无图形会话或工具不可用时，请手动输入项目绝对路径。

## 使用

1. 点击“浏览目录”使用系统窗口选择目录（选择后回填路径，取消保留原值），再点击“打开项目”；也可手动输入绝对路径。勾选要授权修改的文件或目录；未勾选的关联文本可读取，但不能修改。
2. 创建默认的“单轮修复”流程，在画布上添加、连接和配置节点。
3. 选择“确认后写入”或“自动写入”，启动工作流。启动时固定文件范围、工作流和原内容基线；运行期间的配置修改只影响下一次运行。
4. 逐条审核检查命令，查看程序、目录、用途和内容哈希；拒绝不会执行。自动写入也需要逐次批准。
5. 查看节点结果和各轮差异；确认模式需手动应用，自动模式在验证完整后整批应用。应用后可撤销，也可导出报告或查看历史。

默认单轮修复包含 6 个节点：上方为读取 → 审查 → 有阻塞问题？ → 输出，下方为修复 → 复审，沿执行顺序从左向右排列。有阻塞问题才修复，复审后无论是否仍有问题均结束并报告，最多执行一次修复；必要验证缺失时停止，不继续修复。产品只保留这一预置模板；需要其他流程时可自行编辑或导入已有工作流。

加载模板、服务器工作流或导入文件前，有修改时可取消、保存后替换或直接替换；替换支持一步撤销，刷新后仍可恢复。加载默认模板会替换当前草稿，清除旧连线选择并在新节点测量完成后适配全图；普通页面切换保留视口。保存、导入和历史中的工作流保持原节点、坐标和循环配置，不会自动转换为默认模板。

## 工作台

打开页面先进入欢迎页，可打开项目、创建模板、继续编辑或查看历史。编辑页左侧为资源面板、中间为画布、右侧为节点配置／运行设置，下方为执行结果；面板可收起，分隔线可拖动或用键盘调整，布局保存在本机浏览器。右上角可切换系统、浅色或深色主题。中央区域至少 400px；双侧栏放不下时显示最近操作的一侧，默认配置栏优先，加宽后恢复双栏偏好。结果工具栏自动换行，不再固定收起高度。

结果区提供整次运行的问题列表及严重程度、状态、文件和节点筛选，直接显示描述、证据、建议与行号；点击行号查看经过版本校验的只读源码。运行名称、时间、项目和范围始终随结果保留，修改草稿后旧节点状态不混入草稿，可切换只读运行快照或按该次配置重跑。输入、完整版本和原始 JSON 默认折叠。结果区显示执行记录和差异；待审核命令独立显示，切换欢迎页或历史页仍可批准或拒绝。窗口宽度小于 768px 时显示限制提示，加宽后恢复；后台运行和事件连接会保留。刷新页面回到欢迎页，并恢复上次运行显示；本地草稿自动恢复，包含项目路径、排除规则、范围、节点和未应用 JSON；服务器保存仍需主动操作。本地存储不可用时显示提示并启用离开提醒。

## 大项目与模型限制

文件树默认折叠，支持路径搜索、全部折叠、路径复制和逐项移除范围；过滤与折叠不改变授权。可见行虚拟滚动，显式选择数与实际覆盖文件数分别显示。打开项目只保存索引与统计，可取消扫描；打开前可编辑默认排除规则，失败重试保留路径与规则。大目录统计中的排除建议只有点击后才加入规则，再次打开项目生效。

不再限制 1000 文件、1000 项选择或 16 MiB 总文本；不再设置 64 KiB 模型历史、512 KiB 节点累计读取、21 次请求或 20 次工具调用门禁。仍保留单文件 1 MiB、单次读取 256 KiB（分页）、路径与权限检查、逐次命令审核和整批文件事务。项目仍受本机内存、磁盘与供应商窗口约束。

DeepSeek 继续使用 `deepseek-flash` 和 Chat Completions，新节点不发送 `max_tokens`，显式配置支持 1–393216，旧工作流数值不改写。按官方窗口与输出余量估算，在可用输入空间 80% 时压缩完整旧交互，保留最近四组与原始思考历史；摘要不能替代读取、版本或验证证据。供应商明确超窗时进一步压缩并重试一次；摘要用量计入调用统计。每节点总时限 **10 分钟，包含摘要和审核等待**；单请求及命令各 120 秒，支持手动取消。

`POST /api/workspaces` 兼容 JSON；加 `Accept: text/event-stream` 可接收 `progress`、`complete`、`error`。鉴权的 `GET /api/runs/[id]/source?path=...&version=...&startLine=...&endLine=...` 从运行基线、差异或副本恢复对应版本，无法验证时明确不可用，绝不回退到当前磁盘。原始交互与压缩记录写入数据目录 `interactions/<run-id>.jsonl`，目录 0700、附件 0600，不通过 SSE 重传全文，删除运行时一并清理。
